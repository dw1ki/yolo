🎯 HASIL.PNG - MAIN TRAINING METRICS (9 Grafik)
═══════════════════════════════════════════════════════════════════════════════

Grafik ini menunjukkan **60 EPOCHS** (60 iterasi training) dengan data dari VALIDATION set.

DATA ASALNYA: 
  • Training data: 798 images dari dataset_combined
  • Validation data: 179 images dari dataset_combined
  • Source: Video 008 (514 train) + WhatsApp (167 train) + validation set

Penjelasan 9 subplot:

1️⃣ TRAIN/BOX_LOSS (kiri atas)
   ├─ Apa? = Error dalam prediksi posisi bounding box
   ├─ Data dari? Training set (798 images)
   ├─ Arti: Semakin turun = model semakin akurat dalam menentukan posisi box
   ├─ Hasil: Dari 1.7 → 1.3 (GOOD! menurun konsisten)
   └─ Status: ✅ Convergence

2️⃣ TRAIN/CLS_LOSS (tengah atas)
   ├─ Apa? = Error dalam klasifikasi class (Car/Bus/Truck)
   ├─ Data dari? Training set (798 images)
   ├─ Arti: Semakin turun = model semakin yakin klasifikasi benar
   ├─ Hasil: Dari 1.8 → 0.7 (EXCELLENT!)
   └─ Status: ✅ Very good convergence

3️⃣ TRAIN/DFL_LOSS (kanan atas)
   ├─ Apa? = Distribution Focal Loss (confidence level untuk deteksi)
   ├─ Data dari? Training set (798 images)
   ├─ Arti: Semakin turun = model lebih confident dalam deteksi
   ├─ Hasil: Dari 1.7 → 1.1 (menurun, good)
   └─ Status: ✅ Good

4️⃣ VAL/BOX_LOSS (kiri bawah)
   ├─ Apa? = Error dalam prediksi posisi box pada VALIDATION set
   ├─ Data dari? Validation set (179 images) - DATA YANG BELUM PERNAH DILIHAT SAAT TRAINING!
   ├─ Arti: Ini adalah test di data BARU! Menunjukkan generalisasi model
   ├─ Hasil: Dari 1.45 → 1.3 (stabil, tidak overfitting berat)
   └─ Status: ✅ Good generalization

5️⃣ VAL/CLS_LOSS (tengah bawah)
   ├─ Apa? = Error klasifikasi pada validation set
   ├─ Data dari? Validation set (179 images)
   ├─ Arti: Model akurat klasifikasi pada data baru
   ├─ Hasil: Dari 9 → 4.5 (menurun baik, tapi lebih unstable dari training)
   └─ Status: ⚠️ Acceptable variance (normal)

6️⃣ VAL/DFL_LOSS (kanan bawah)
   ├─ Apa? = Confidence loss pada validation
   ├─ Data dari? Validation set (179 images)
   ├─ Arti: Model lebih confident pada data baru
   ├─ Hasil: Dari 1.2 → 1.1 (stabil)
   └─ Status: ✅ Good

7️⃣ METRICS/PRECISION(B) (tengah, row 1)
   ├─ Apa? = Precision untuk detection boxes
   ├─ Data dari? Validation set (179 images)
   ├─ Formula: TP / (TP + FP) = yang benar / semua yang diprediksi positif
   ├─ Arti: Dari deteksi yang model buat, berapa % yang benar?
   ├─ Hasil: Naik dari 0.15 → 0.45 (model belajar jadi lebih precise)
   └─ Status: ⚠️ Masih ada variance (normal untuk training yang belum sempurna)

8️⃣ METRICS/RECALL(B) (kanan, row 1)
   ├─ Apa? = Recall untuk detection boxes
   ├─ Data dari? Validation set (179 images)
   ├─ Formula: TP / (TP + FN) = yang benar / semua yang seharusnya ada
   ├─ Arti: Dari obyek yang ada, berapa % yang model temukan?
   ├─ Hasil: Dari 0.25 → 0.64 (model lebih bisa menemukan obyek)
   └─ Status: ✅ Improving trend

9️⃣ METRICS/mAP50(B) dan mAP50-95(B) (bawah)
   ├─ Apa? = Mean Average Precision @ threshold 0.5 dan 0.5-0.95
   ├─ Data dari? Validation set (179 images)
   ├─ Formula: Average dari precision di berbagai confidence thresholds
   ├─ Arti: Overall detection quality score
   ├─ Hasil: 
   │   • mAP50 = 0 → 0.625 (bagus!)
   │   • mAP50-95 = 0 → 0.4 (bisa lebih baik, tapi acceptable untuk combined model)
   └─ Status: ✅ Reasonable performance untuk 2 video source

    • Record metrics: loss, precision, recall, mAP
    • Save best model ketika validation performance terbaik
